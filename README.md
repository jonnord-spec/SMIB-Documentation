# епозиторий документации С

## азначение
епозиторий предназначен для хранения и контроля изменений
документированной информации системы менеджмента
информационной безопасности (С).

## Структура
- 01-politika — политика информационной безопасности.
- 02-chastnye-politiki — частные политики.
- 03-procedury — процедуры и регламенты.
- 04-instrukcii — инструкции, шаблоны и чек-листы.
- 05-zapisi — шаблоны и записи, подтверждающие выполнение процессов С.

## орядок внесения изменений
1. Создать отдельную ветку для изменения документа.
2. нести изменения и проверить содержание.
3. афиксировать изменения информативным коммитом.
4. Создать Pull Request и назначить рецензента.
5. справить замечания и выполнить слияние после согласования.

## онтроль редакций
стория изменений хранится в Git.
тверждённые редакции обозначаются тегами.
